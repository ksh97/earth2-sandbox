# data

Local weather data belongs here.

Do not commit:

- Original weather datasets
- Intermediate model arrays
- Forecast output archives
- Large generated files

Keep only small documentation files in this folder.

For local FourCastNet experiments, place any real NVIDIA tar response files here or in a
local subfolder such as `data/samples/`. Keep those files untracked; they can be large
and may reflect licensed model outputs.
